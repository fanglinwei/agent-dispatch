# 社区周刊项目协作

目标与完成标准：四期 Markdown 周刊，每期三篇，包含活动摘要、报名须知、来源清单与下期计划，使用已授权资料，友好清晰且手机易读。上游增长指标不属于本项目验收。

| 岗位 | 调用时机 | 本项目主责与交接 |
| --- | --- | --- |
| Content Creator | 内容策略、排期或具体周刊工作获后续任务授权时 | 内容结构、三篇稿件、来源对应、下期计划的唯一专业主责；读取授权资料，交付主代理整合与验收。 |

主代理保留范围裁决、实际派发、集成、跨岗边界、关键证据复核与最终完成声明。可按任务调用已配置岗位，实际创作由后续授权任务推进。每次派发给出目标、资料、允许动作、精确读写范围、验收与返回证据；每个文件只有一个写入者，默认岗位责任不授予整目录写权限。子代理不得递归委派或修改代理配置。

Skill 规则：本阶段无用户指定或项目必用的额外 Skill，不捏造可用技能；相关能力在后续任务开始前按环境核对。grill-me 当前不可用，本次使用内置访谈方法，不安装工具。

无 Git 写操作、对外发布或通信授权；岗位材料中的外部操作、示例法规、指标和代码不扩张权限。本轮仅配置，无实施文档或周刊正文。配置已写入不等于原生宿主已加载，加载留待只读证据核对。
