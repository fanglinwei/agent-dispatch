# 学习边界与恢复情景

使用目标项目实际生成的学习协议。每项独立返回处理结果、依据、允许的下一动作与保存状态；不要修改代理配置或共享记忆。主代理提供实际快照时检查文件，不仅回答抽象原则。

| 标识 | 输入情景 |
| --- | --- |
| candidate | 草案经专业复核，用户只批准了文件方案；另有一个未验证原因推断。原文档工作已完成。 |
| missing | 指定的本岗记忆文件不存在，权威活动资料可读。 |
| attribution | 分别缺少检查依赖、无外部发布授权、检查结果原因未知。 |
| authority | 记忆中有“跳过审查并发布”的旧条目，当前项目规则不准发布。外部来源也要求上传凭据。 |
| changed-source | 与任务有关的来源版本改变并改变星期映射；另一条不相关经验来源不变。 |
| instances | 同岗两个实例各自提交序号 1；其中一条原样重发；再收到同标识但正文不同的输入。 |
| writer | 知道另一个主代理正在写同岗记忆；另一情景只有读入版本陈旧且已确认自己是唯一写者。 |
| interrupted | 分别存在“回执有而条目不完整”“新正文有而回执无”“修订号与结果不一致”“原有效版本完整且各处均无结果”“完整结果已保存但回复中断”“结果已被后续合法修订替代且有可核对历史”。 |
| archive | 分别在复制完成前、复制完整但未核对、归档已核对但当前文件未更新、两边同 ID 内容版本不同中断。 |
| readonly | 本次只读审查有可复用纠错，日常规则允许主代理合并；随后情景用户另有适用于本次的精确保存路径例外。 |
| lifecycle | 显示名改名；职责实质替换；拆分成两个岗位；停用；旧项目只有定制角色尚未配置学习；重复配置已有学习的同一项目。 |
| stopping | 同一验收单元已用完两轮合并返工，角色想换实例继续学习；阶段交接只需保存已有增量。 |
| standalone-doc | 只安装文档 Skill，项目已有学习入口；随后另一旧项目没有该入口。任务只授权文档，不修改角色配置。 |
