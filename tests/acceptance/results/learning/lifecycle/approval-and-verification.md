# 迁移与改名的隔离验证
模拟用户在完整路径方案后批准主代理迁移 legacy-before 到 legacy-after：保留旧角色文件中现有字段、模型、完整专业正文及用户审稿定制，仅在 developer_instructions 追加项目读取指引；复制协议、创建空本岗记忆、追加入口及精确日常维护授权。实际迁移由主代理执行，字段对照与 tomllib 解析通过。
另一个独立副本模拟批准角色显示名与配置文件改名为 Community Editor / community-editor.toml；仅改实际 name、配置路径映射，稳定 key 和记忆路径均为 content-creator。主代理实际执行文件移动及映射调整，tomllib 解析通过，完整记忆 SHA-256 与改名前一致。
这些模拟批准不表示真实用户项目授权；未执行拆分/合并/停用，那些仅在边界报告验证决策。
