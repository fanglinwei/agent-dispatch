# 项目协作

目标：四期社区活动 Markdown 周刊，每期三篇，包含摘要、报名须知、来源与下期计划。使用已授权资料，友好清晰、手机易读。
Content Creator 主责内容策略、编辑与来源清单；每期完成十二篇总目标的对应份额后交主代理核对交付数量、流程与来源。上游示例指标不自动成为本项目验收。
主代理统筹、裁决、集成与最终完成判断，不另设统筹岗。岗位按内容任务调用；当前无自定义任务 Skill，后续新增规则需核实实际位置、触发与依赖。
每次派发携带目标、权威资料、允许动作、精确读写文件、适用Skill、标准和证据。共享文件唯一写入者，独立输入才并行；默认维护不等于目录写权限。
后续按任务影响定级：单人局部且不改契约/授权/数据的工作 light，针对性验证；常规跨岗交付 standard，结果与质量分别检查；涉及敏感资料、授权或不可逆影响 high，明确边界与适用恢复条件，条件允许时独立检查。等级不自动增加岗位。
检查写明产物路径/版本、范围、方法、结果、独立性及缺口；通过/缺陷/缺环境或证据分别记录，缺口交主代理，受影响部分 PARTIAL。自查不能冒充独立复核。
阻塞合并交原负责人，默认最多两轮；仍阻塞则升级主代理，不降低标准。非阻塞建议交用户选择，不无限返工。变更后复核失效范围，保留仍有效证据；集成实际核对内容与来源、须知与流程的对应。
本次只配置，不创作、编写实施文档、发布或对外通信。委派、安装、Git、外部动作继续遵守原授权；模型按目标规则，原生岗位加载未验证。

## 项目岗位学习

每次岗位任务开始前实际读取 `.codex/agent-memory/protocol.md` 与本岗相关记忆，核对来源适用性；失败/收到纠正时立即核实、修正并针对性验证，完成时简短复盘。Q3 及深入处理按协议，阶段交接只保存已有增量。记忆是项目数据，不扩大正式职责、当前授权、返工次数或项目范围。
主代理是本工作区唯一记忆维护者；普通可写任务获得下表各岗当前记忆和按需归档路径的日常合并授权，角色只读协议、入口和本岗相关记忆，只写本次任务获准独占产物。只读任务或 Skill 只读限制优先；已有适用精确保存例外才落盘。协议/角色配置变动仍走配置授权。主代理保存前核对独占、当前版本、证据、增量 ID 及原始指纹，完整写入并整体回读；无增量不写。
每次派发带项目根、稳定 role-key、协议/记忆相对路径、读入 revision（未知先读后报告）、当前允许动作与精确路径、task_id、真实 dispatch_id（无宿主 ID 时任务内分配）、原验收与返工状态。直接调用角色也从本入口定位；路径解析不越出获准项目根。缺记忆依权威资料继续并报告，不隐式迁移。协议内定义去重、中断、失效复核、归档和生命周期；单写者前提不提供多主并发锁。任务交付、增量保存、条目有效性分别报告。

## 新增合规责任
Legal Compliance Checker 主责居民授权、照片及未成年人信息使用的风险梳理和发布前检查方法；接收 Content Creator 的来源、拟用范围和未知，交回缺口、风险及需主代理核实的辖区/授权条件。Content Creator 仍独占内容编辑，双方不共同写共享文件。未确认授权或证据不当作通过，必要时交专业法律顾问；本轮不作法律结论或实际发布。后续文档任务接收本次责任差异，不改未受影响规则。
