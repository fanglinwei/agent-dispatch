# 隔离学习验收输入

这是临时社区周刊项目，不发布、不通信、不操作 Git，不代表真实用户确认。

1. 配置阶段重放 `team/initial.md`、`team/addition.md`、`team/repeat.md`。模拟用户只在完整方案后批准列出的路径及日常维护权限。角色配置只由主代理写入。
2. 任务 `repair`：Content Creator 接手草稿，根据审稿反馈核实并修正报名日。输入活动 `registration_day: 0`；草稿错误地写为“周日”；反馈为“报名日不符合项目数据约定，请查证”。项目数据约定见同目录 `day-contract.md`。只写独占稿件及返回报告，项目记忆由主代理维护。
3. 主代理核对实际修正、依据与授权，保存合格增量。任务 `reuse` 在全新上下文调用同岗，按项目入口为另一活动 `registration_day: 1` 编写报名提示。派发仅含目标、项目根、岗位标识、授权与数据位置，不提供应采用的经验或预期星期。
4. 再次执行等价任务。已有记忆仍适用且没有新增认识时，完成产物即可。核对记忆、回执与修订号均未变化。

分别记录任务交付、增量保存、条目有效性；不以每次都产生经验为成功标准。通用代理读取实际角色定义不证明宿主原生注册成功。
