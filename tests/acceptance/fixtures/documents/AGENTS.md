# 项目协作
项目是给社区活动主办者使用的浏览器报名工具，Vue 3 / TypeScript / REST API。
角色已确认覆盖本阶段需求，保留现有角色名称和模型。
product_owner 负责需求与流程；ui_owner 负责视觉和交互；frontend_owner 负责页面实现；delivery_qa 负责验收及 API 错误、权限与重复提交；code_auditor 只读检查代码缺陷。
主代理负责集成、共享边界和完成声明。共享文件每次只能有一个写入者。
既有 docs/legacy-design.md 是上个阶段的设计。代码事实与最新用户决定优先，Git 写操作未授权。
浏览器设计任务必须使用 visual-layout。实际代码审查必须使用 review-method。
