# 测试用户请求：首次团队配置

显式使用 $agent-dispatch。项目是一份面向社区居民的四期活动周刊，每周交付一期 Markdown，包含活动摘要、报名须知、来源清单与下期计划。共四期，每期三篇，内容以社区提供的已授权活动资料为依据，语气友好清晰，手机易读。主代理负责统筹，不另设统筹岗。

本阶段只配置完成内容工作的必要岗位与协作规则，不实际创作周刊，不生成实施文档，不发布，不执行 Git 写操作。当前没有岗位、旧文档或自定义 Skill；grill-me 不可用。上游候选和许可在 upstream/，来源提交见 source.json。项目类型、工作内容、工具、风格和交付程度已经明确，不重复问已确认问题；先展示完整可批准方案。

本例的模拟用户可在看到完整方案后批准配置；这不是给实际用户项目的预先授权。
